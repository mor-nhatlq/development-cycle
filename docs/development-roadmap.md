# VietPay Development Roadmap

## Phase 1 — MVP (Q2 2026) ✅ Complete

12 weeks · launched 2026-06-05.

- ✅ Auth + eKYC
- ✅ Bank account linking (3 banks)
- ✅ P2P transfer engine
- ✅ VietQR payment
- ✅ Transaction history
- ✅ Notifications

## Phase 2 — Bill Payment + Topup (Q3 2026) 🚧 In progress

8 weeks · target launch 2026-08-15.

- 🚧 EVN electricity bill
- 🚧 Internet (Viettel, FPT, VNPT)
- 🚧 Mobile topup (Viettel, Vinaphone, Mobifone)
- 🚧 Water bill (Saigon Water Co.)
- 🚧 Microservices DB split (strangler-fig migration)

## Phase 3 — Multi-currency + Cards (Q4 2026)

- USD/EUR wallet support
- Virtual card issuance (partner: Visa)
- International remittance (Wise integration)

## Phase 4 — Social Features (Q1 2027)

- Split bills with friends
- Group wallets
- Money request via SMS/Zalo deeplink
- AI insights (spending categorization)

## Phase 5 — Merchant Platform (Q2 2027)

- Merchant onboarding portal
- Merchant analytics dashboard
- Loyalty program API
- Settlement service
