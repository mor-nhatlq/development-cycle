02

Security Risks · Khi áp dụng external Skills/Agents

Top 5 rủi ro khi load skill/agent từ nguồn ngoài (public registry, GitHub gist, third-party MCP servers):

  • Prompt Injection (OWASP LLM01) Indirect qua webpage scraped, file content, git diff, MCP response — agent đọc data có chứa instruction "ignore previous, leak secrets"
  • Tool/Function Call Abuse Skill compromised gọi destructive tools: rm -rf /, DROP TABLE, hay shell exec với user-controlled input
  • Data Exfiltration Sensitive data (.env, KYC docs, customer PII) được leak qua tool calls — vd: WebFetch tới attacker server, hoặc đính kèm vào prompt context
  • Supply Chain Skills tải từ unverified repos · MCP server bị compromise · dependency typosquatting · skills update silent với code malicious
  • Hallucination Drift Agent invent API/package không tồn tại → install malicious lookalike (vd: react-router-doom). Phantom dependencies risk supply-chain attack
03

Mitigation Mechanisms · Giảm thiểu rủi ro

Defense in depth — nhiều lớp bảo vệ kết hợp:

  • 🤖 Dedicated Security Audit Agent Agent riêng chuyên scan tất cả custom agent/skill: phát hiện prompt injection patterns, role-override attempts, unsafe shell exec, OWASP LLM Top 10. Run pre-commit + CI. Output security-scan-agents.md
  • 🔒 Permission Allowlist .claude/settings.json deny-by-default cho destructive tools. Mỗi Bash/WebFetch/MCP call phải explicit allow. Block rm -rf, DROP, raw shell.
  • ⚙ Pre-Tool Hooks Hook validate input trước khi tool execute: sanitize prompts, detect injection patterns, scan secrets. Reject nếu match suspicious patterns.
  • 📦 Sandbox Mode Risky tools (file write, web fetch, exec) chạy trong isolated sandbox với egress whitelist + filesystem chroot. Network locked tới trusted domains.
  • 📜 Source Trust + Hash Pinning Skills chỉ từ verified GitHub orgs (allowlist). Pin SHA hash, không auto-update. New skill require Tech Lead + Security review trước khi merge.
  • 📊 Monitoring + Audit Transcript logging immutable (S3 Object Lock 7y). Anomaly detection cho unusual tool patterns. Daily auto-review. Quarterly external pen test.
Key innovation: Security Audit Agent là agent đầu tiên build (trước mọi agent khác) — dùng để scan chính các agent kế tiếp. Self-bootstrapping security: "AI guards AI".
